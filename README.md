## ✨ Features

### 🛡️ Built-in Ad Blocker
- Automatically blocks ads, trackers and malicious domains
- No extensions needed — it's baked right in
- Toggle on/off from the menu

### 🕵️ Incognito Mode
- Full private browsing — no cookies, no history, no storage
- Auto-applies dark overlay to pages for visual feedback
- Clears all data on exit

### 💻 Desktop Mode
- Switch to a full desktop user agent with one tap
- Forces websites to load their full desktop version

### 📖 Reader Mode
- Strip all distractions and read articles in a clean, beautiful layout
- Auto-detects article content

### 🔍 Find in Page
- Search any text on the current page
- Previous/Next navigation with result count

### 📸 Screenshot Tool
- Capture the full visible webpage
- Saved to your gallery instantly

### ⭐ Bookmarks & History
- Save your favorite pages
- Full browsing history with quick search
- Clear data anytime

### 🗂️ Multi-Tab Support
- Open unlimited tabs
- Tab counter with animated badge
- Incognito tabs supported

### 🎨 Modern Design
- Gorgeous gradient color scheme (Purple → Pink)
- Smooth micro-animations throughout
- Adaptive dark/light mode
- Glassmorphism-inspired UI elements
- Home screen with quick links grid

### 🔒 Security Indicators
- Green padlock for HTTPS sites
- Red warning for HTTP sites
- Geolocation & camera permission management

## 🏗️ Build Instructions

### Requirements
- Android Studio or Android SDK (API 34)
- Java 17+
- Gradle 8.4+

### Build
```bash
git clone https://github.com/dor2500/NovaBrowser.git
cd NovaBrowser
./gradlew assembleDebug
```

The APK will be at:
```
app/build/outputs/apk/debug/app-debug.apk
```
